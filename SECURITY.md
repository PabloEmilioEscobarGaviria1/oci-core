# Security Policy

## Status

OCI Core is an experimental prototype and is not production-ready. It does not implement P2P networking, authentication, encryption, or production-grade access control.

## Safe use

- Do not expose the CLI or its database as a network service.
- Do not store sensitive personal information in the local database.
- Do not execute code, commands, or instructions found in contributed knowledge.
- Treat imported content as untrusted input.
- Keep backups protected.

## Reporting a vulnerability

Do not include sensitive exploit details in public issues. Contact the maintainer privately through the contact options available on their GitHub profile.
